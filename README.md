# 오아시스노트 (OasisKnot)

출장마사지·홈타이 방문 안내 정적 사이트. 외부 의존성 없이 Node 20 표준 라이브러리만 쓴다.

## 돌리는 법

```bash
npm run regions   # 행정동 경계 → data/regions.json (원본 geojson 필요)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사
npm run simil     # 동 안내문끼리 본문 겹침 측정
npm run serve     # dist/ 를 로컬에서 띄워 보기
```

## 호스팅 — Cloudflare Workers

`wrangler.jsonc`(이름 `oasisknot`)가 `dist/` 를 정적 자산으로 올린다. Workers Builds 에 저장소를 연결하면 아래 값으로 돈다.

| 칸 | 값 |
|---|---|
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| 환경 변수 | `NODE_VERSION` = `20` |

기준 주소는 `data/site.config.json` 의 `siteUrl` 이고, 빌드할 때 `SITE_URL` 환경 변수를 주면 그 값이 먼저 쓰인다.

## 이 사이트가 구하는 값 — 북위 눈금

동 땅의 무게중심이 북위 몇 도에 놓였는지만 읽는다. 길이나 동서 방향은 재지 않고 위도 하나가 전부다.

| 값 | 뜻 |
|---|---|
| 북위 | 무게중심의 위도(°, 화면에는 소수 둘째 자리) |
| 북쪽부터 순서 | 같은 시군구 동을 북위가 높은 순으로 세운 번호(n곳 중 m번째) |
| 내려앉은 거리 | 시군구에서 가장 북쪽인 동과의 위도 차 × 111.2km (소수 첫째 자리) |
| 시군구 북위 폭·평균 북위 | 소속 동(동이 없으면 읍·면) 무게중심의 최북단~최남단 km, 평균 위도 |
| 시도 평균 북위·폭 | 소속 시군구 평균 북위의 평균, 최북단~최남단 시군구의 간격 |
| 갈래 | 일곱 가지: 맨 위 눈금 · 북쪽 넓은 구간 · 북쪽 좁은 구간 · 가운데 구간 · 남쪽 좁은 구간 · 남쪽 넓은 구간 · 맨 아래 눈금 |

갈래는 시군구 안(시군구는 시도 안) 북쪽 몫을 삼등분하고, 폭이 넓은지(동 기준 6km, 시군구 기준 10km 이상)로 나눈다. 검산은 단순한 위치로 한다: 위도가 0.01° 다르면 1.1km, 같으면 0이다.

## 커버리지

- **동까지** 서울·인천·경기·부산 — 1,232구역
- **시군구까지** 대전·대구·울산 전역 + 광주 광산구 + 지정 시·군
- 읍과 면은 안내문을 내지 않고 시군구 목록에 이름만 적는다(접수와 방문은 동일).

## 화면 골격

방송국 편성표 — 맨 위 로고 띠(ON AIR 램프), 채널 메뉴, 코너 번호가 붙은 칸, 줄마다 북위 막대가 달린 편성표 줄, 라디오 다이얼 그림, 채널 안내 바닥글. 홈은 시도 다이얼(라디오 버튼 + CSS, 스크립트 없음)로 지역을 고른다.

## 꼭 지킬 것

- `data/lastmod.json` 을 **반드시 커밋**한다. 없으면 깃 빌드에서 전 안내문이 '오늘 수정'으로 밀린다.
- 전화번호는 `callBox()` 로만 찍는다. 맨 번호가 본문에 남으면 `npm run check` 가 잡는다.
- 무작위를 쓰지 않는다. 모든 변형은 md5 시드 고정이라 같은 주소면 언제나 같은 HTML 이 나온다.
- 후기·체험담·평점·인물 사진을 싣지 않는다.
- 한글 문장은 `src/content/copy.mjs`(T), 값을 말로 옮기는 말은 `src/content/metric.mjs`(M), 마크업은 `src/lib/skin.mjs`(SK)에만 둔다. `src/lib/blocks.mjs`·`src/pages/region.mjs` 에는 한글 문장이 없다.
